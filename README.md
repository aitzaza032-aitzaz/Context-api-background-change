# Contact API

A simple and responsive **Contact API** project that allows users to submit their contact information and messages through a web interface.

## 🚀 Live Demo

[Live Demo]  =====> https://aitzaz-context-api.netlify.app/

## 📌 About The Project

This project is built to demonstrate how a contact form can communicate with an API and handle user-submitted messages.

Users can enter their information and send a message through the contact form. The frontend sends the data to the backend API using an HTTP request.

The project focuses on understanding the basic flow of a full-stack application:

**User → Frontend → API → Backend → Response**

## 🔄 How It Works

1. User opens the contact form.
2. User enters their name, email, and message.
3. Frontend sends the form data to the backend API.
4. Backend receives the POST request.
5. Backend processes the submitted data.
6. API sends a response back to the frontend.
7. Frontend displays the result to the user.

## 📡 API

The project demonstrates the use of a REST API, particularly a **POST request** for submitting contact information.

Example request:

```http
POST /api/contact
```

Example data:

```json
{
  "name": "Aitzaz Ahmad",
  "email": "example@gmail.com",
  "message": "Hello, I would like to contact you."
}
```
